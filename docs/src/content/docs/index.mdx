## Why CondaTainer

<div class="numbered-cards">
	<CardGrid>
		<Card title="Modular">
			Conda environments and data as separate images that work together.
		</Card>
		<Card title="Reproducible">
			Pin exact versions per project and share them through OCI registries.
		</Card>
		<Card title="Scheduler Native">
			Works with HPC schedulers such as Slurm.
		</Card>
		<Card title="Web-App Ready">
			Run *RStudio*, *code-server*, *Jupyter* and *VNC* on compute nodes from a dashboard.
		</Card>
	</CardGrid>
</div>
